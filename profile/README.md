# shfmt-py

[shfmt](https://github.com/mvdan/sh), the shell script formatter, packaged for Python and
[pre-commit](https://pre-commit.com): `pip install shfmt-py` puts the upstream binary on your
`PATH` and gives you a ready-made pre-commit hook.

**The project lives at [MaxWinterstein/shfmt-py](https://github.com/MaxWinterstein/shfmt-py)** —
docs, issues, pull requests and releases are all there. Packages are on
[PyPI](https://pypi.org/project/shfmt-py/).

This organization just holds the `shfmt-py` name.
